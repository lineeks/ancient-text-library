# Aether-Cycle · 子平命理古籍知识库

> 面向八字排盘引擎的结构化古籍文库：**即时检索 · 引经据典 · 原汁原味**。
> 每条古籍条文以 Markdown + YAML Frontmatter 标引，排盘内核输出 `日干 / 月令 / 格局 / 十神 / 神煞` 后，
> 对 `conditions` 字段做数组交集匹配，毫秒级返回 **【原文】 / 【注解】 / 【白话提要】** 三层内容。

## 二、文件命名规范（为什么文件名是英文）

为保证跨平台、跨语言、Git 与代码 `import` / 路径匹配稳定，**所有 Markdown 文件名一律使用 ASCII 英文小写**，
中文标题只出现在文件内的 Frontmatter（`section_title` / `chapter`）与正文标题中。
文件名 = **典籍缩写 _ 定位键**，全局唯一。

## 三、Frontmatter 字段规范

每个 `.md` 文件以 YAML Frontmatter 开头，字段即引擎的检索索引：

```yaml
---
id: "qtbj_jia_yin"              # 全局唯一编号，与文件名一致（不含扩展名）
book: "穷通宝鉴"                 # 典籍名称
chapter: "甲木·寅月"             # 卷章节名
section_title: "正月甲木"        # 条目标题（中文）
source_version: "余春台辑本"     # 版本出处
author: "余春台"                 # 作者/编者
dynasty: "清"                    # 朝代
type: "monthly"                  # monthly 月度 | seasonal 季度 | chapter 章节 | reference 总论
conditions:                      # —— 命理匹配规则（引擎检索核心）——
  day_master: ["Jia"]            #   匹配日干（英文，见对照表）
  month_branch: ["Yin"]          #   匹配月令地支（英文；合并月可多个）
  day_pillar: []                 #   匹配日柱（三命通会日时断用）
  hour_pillar: []                #   匹配时柱
  ten_god: []                    #   匹配十神：正官/七杀/正财/偏财/正印/偏印/伤官/食神/比肩/劫财
  pattern: []                    #   匹配格局：正官格/七杀格/财格/印格/伤官格/食神格/建禄格/阳刃格/从格/化格…
  shensha: []                    #   匹配神煞：天乙贵人/文昌/驿马/华盖…
  keywords: ["调候用神", "寅月"]  #   关键词索引（模糊召回用）
weight: 10                       # 多书命中时的排序权重：第一梯队 10，季度 8，参考 5
tags: ["甲木", "寅月", "调候"]
---
```

### 三部典籍的检索差异

- **穷通宝鉴（调候）**：只填 `day_master` + `month_branch`，排盘算出日干月令后 **100% 精确锚定**。
- **子平真诠（格局）**：`day_master/month_branch` 留空，主要填 `pattern` + `ten_god`，格局评定后按格局召回。
- **滴天髓阐微（气象/理气）**：同样不按日干月令精确锚定，而以 `pattern`（从格/化格/八格等）、`ten_god`（官杀/伤官/印比食）与 `keywords`（衰旺、顺逆、寒暖燥湿、通关、从化、六亲情志等）做主题召回，weight=9，作为格局与旺衰判定后的**理论依据层**。

## 四、正文三层结构（原文锁死，不可篡改）

```markdown
### 正月甲木

**【原文】**
正月甲木，初春尚有余寒，得丙癸逢，富贵双全……

**【徐乐吾评注】**        <!-- 仅当该版本含注时出现；穷通宝鉴辑本无注则省略 -->
……

**【附：命例】**          <!-- 穷通宝鉴所附「时日月年」四柱实例，代码块保留原貌 -->
​```text
时日月年
庚丙庚丙
寅午寅午
​```

**【白话提要】**
（待补）                  <!-- 仅作文义解释，严禁添加现代断命结论 -->
```

铁律：
1. **【原文】一字不改**，异体字、通假字（如「端用」即「专用」、「後」即「后」）均保留原貌；
2. 【注解】与【原文】分层渲染，不得混排；
3. 【白话提要】只解释文义，不新增吉凶判断，当前批次标注「待补」，后续人工校补；
4. 命例（时日月年四柱）是原书附例，统一收入 `【附：命例】` 代码块，不与断语正文混淆。

### 滴天髓阐微的特殊分层（一篇多口诀体例）

《滴天髓》一篇之内常含**多句赋文口诀**，每句口诀下依次接「刘伯温原注 → 任铁樵阐微 → 附命例」，
故不使用穷通宝鉴/子平真诠的【原文】层，而按原书顺序就地分为五层，层与层严格区隔：

| 层标记 | 内容 | 出处 |
|---|---|---|
| **【经文】** | 传世赋文口诀（如「甲木参天，脱胎要火」） | 传宋·京图 |
| **【刘伯温原注】** | 明代原注（源文「原注：/原注，/原注；」三种标点均已兼容） | 明·刘伯温 |
| **【任铁樵阐微】** | 任氏阐微与命例分析（源文「任氏曰：」） | 清·任铁樵 |
| **【附：命例】** | 四柱 + 大运纯干支序列，```text 代码块 | 任氏所举实例 |
| **【校勘按语·若思】** | 仅 3 处现代校勘者「若思按」，单独成层，**不属古籍** | 现代校勘 |

> 注：「原注云：……」一类句子是任铁樵**引述并反驳**原注，保留在【任铁樵阐微】层，不误判为原注层。
> 六亲论《从象》篇源文即以原注起首、无赋文口诀，属源文体例，已照常分层。

## 五、排盘引擎如何检索（调用逻辑）

程序启动时一次性扫描全部 `.md`，解析 Frontmatter，将 `conditions` 载入内存索引（HashMap）。

```text
排盘内核输出八字
   │
   ├─ 日干=Jia, 月令=Yin ──► 穷通宝鉴：day_master∩month_branch 命中 qtbj_jia_yin.md
   │
   ├─ 格局=正官格        ──► 子平真诠：pattern 命中 ch31/ch32
   │
   ├─ 十神=七杀          ──► 子平真诠：ten_god 命中 ch39/ch40（论偏官/偏官取运）
   │
   ├─ 旺衰/从格/化格/调候 ──► 滴天髓：pattern/keywords 命中衰旺、从象、化象、寒暖燥湿诸篇
   │
   ├─ 日柱=甲子,时柱=丙寅 ──► 三命通会：day_pillar∩hour_pillar（Phase-3）
   │
   └─ 神煞=天乙贵人      ──► 三命通会·神煞库（Phase-3）

多书同时命中时，按 Frontmatter 的 weight 降序展示（穷通宝鉴月度精确命中 10 ＞ 滴天髓/子平格局 9 ＞ 穷通季度 8 ＞ 穷通总论参考 5）。
```

### 参考匹配伪代码

```python
def match(entry: dict, chart: dict) -> bool:
    cond = entry["conditions"]
    for key in ("day_master", "month_branch", "pattern", "ten_god", "shensha"):
        if cond[key] and not set(cond[key]) & set(chart.get(key, [])):
            return False          # 该条目声明了此条件但命盘无一命中 → 不召回
    return True                   # 所有已声明条件均有交集 → 召回
```

## 七、版本校勘说明（重要）

1. **穷通宝鉴存在两个系统**：余春台辑通行本（即本库 `raw/qiongtongbaojian.txt`）与徐乐吾《造化元钥评注》本，
   两者条文有差异。本库以**余春台辑本为正文底本**；`source_version` 如实标注为「余春台辑本」，
   后续接入《造化元钥》时，徐乐吾评注进入【注解】层，不与正文底本混同。
2. **余春台辑本并非严格 10 干 × 12 月 = 120 条**：部分相邻月份源文合论
   （正二月、五六月、八九月、十一二月），己土按三夏/三秋/三冬分季，乙木、丁火未单列十二月。
   本库**忠实源文**，共得月度 106 条 + 季度 3 条 + 总论参考 13 条，完整覆盖情况见
   [`core/qiongtongbj/INDEX.md`](./core/qiongtongbj/INDEX.md) 的「十干×十二月覆盖矩阵」，不凭空拆分或补造条文。
3. **子平真诠评注源文为 UTF-16 LE 编码**，下载后已无损转为 UTF-8；该 txt 正文章节标题缺失，
   本库以 48 章首句指纹定位切分（见 `scripts/parse_ziping.py` 的 `CHAPTERS` 表），仅末尾两章含明确「徐注：」标记。
4. **滴天髓阐微源文为 UTF-8**（来自 `garychowcmu/daizhigev20`，与穷通宝鉴同源），正文 63 篇标题完整，
   但分隔符顿号/空格混用（如「十二  从象」，已统一为顿号）；「原注」后冒号/逗号/分号三种标点混用，已全部兼容。
   全书共识别赋文口诀 135 句、四柱/大运命例 514 处；现代校勘者「若思按」3 处单独分层，不混入古籍；
   《从象》篇源文无口诀、以原注起首，保持原貌。
