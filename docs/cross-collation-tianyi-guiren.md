## 1. 定位与总论

- **三本一致的核心定性**：天乙为最尊之吉神，所至凶煞避藏，主功名官禄；喜生旺、
  忌死绝空亡冲破。
  - 五行精纪：「天乙贵人者，十干之秀气在紫微宫门外，乃天皇大帝，其神为最贵，
    所至六害、一切凶杀，隐然而避」（`wxjj_v14_01`，出《烛神经》）。
  - 三命通会：「天乙者乃天上之神在紫微垣阊阖门外与太乙并列……其神最尊贵，
    所至之处一切防（凶）煞隐然而避」（`smth_ss_tianyiguiren`）。
  - 命理约言：「天乙贵人，天神之尊贵者，舍乎斗牛之间，出乎井鬼之次，
    持恒布德，神煞莫不避藏」（`mlyy_lun20`）。
- **源流关系**：三命通会与五行精纪天乙篇所引唐宋佚书高度重合（《烛神经》《广录》
  《三命提要/指掌》《林开五命》《玉霄宝鉴》《紫虚局》《壶中子》《陈希烈》等），
  五行精纪（宋）按"格"分节保存原料，三命通会（明）将同一批材料融贯为长论并补入
  先天/后天起贵推演；命理约言（清）则反过来做减法与辨伪。三者构成"辑录—汇考—辨正"
  的完整链条。

## 2. 起例对照（核心差异区）

### 2.1 歌诀

| 来源 | 歌诀原文（节） |
|---|---|
| 五行精纪 卷13 | 「甲戊庚牛羊，**乙庚**鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎，此是贵人强」（`wxjj_v13_01`） |
| 三命通会 | 「甲戊庚牛羊……六辛逢马虎明矣」（`smth_ss_tianyiguiren`，未单列乙己句） |
| 命理约言 | 不用歌诀，直列二至临方表，并解「旧歌甲戊庚牛羊等句，盖言……互文见意」（`mlyy_lun20`） |

> 校记见 §6-1：卷13「乙**庚**鼠猴乡」与同书卷14义理、三命、命理约言均不合，
> 当为「乙**己**鼠猴乡」传刻之讹。

### 2.2 两套临支（事实层无争议）与"阳贵/阴贵"命名分歧（关键）

天乙临支其实只有**两套**，诸书所列地支完全一致；真正的分歧是"哪一套叫阳贵、
哪一套叫阴贵（昼贵/夜贵）"——三命通会与命理约言的**命名恰好对调**，工程上切勿
按"阳贵"字样直接取列，应以"起例套 A/B"中性落地。

| 日干 | 套 A（起子顺行） | 套 B（起申逆行） |
|---|---|---|
| 甲 | 丑 | 未 |
| 乙 | 子 | 申 |
| 丙 | 亥 | 酉 |
| 丁 | 酉 | 亥 |
| 戊 | 未 | 丑 |
| 己 | 申 | 子 |
| 庚 | 未 | 丑 |
| 辛 | 午 | 寅 |
| 壬 | 巳 | 卯 |
| 癸 | 卯 | 巳 |

同一套临支，三书命名对比如下：

| | 套 A（起子顺行） | 套 B（起申逆行） |
|---|---|---|
| 三命通会 | **阳贵**（先天坤子位起，顺行） | **阴贵**（后天坤申位起，逆行） |
| 三历会同（五行精纪引） | **旦/昼贵**（"甲戊庚旦丑暮未"） | **暮/夜贵** |
| 命理约言 | **夏至后治阴**那套（"甲日临丑"） | **冬至后治阳**那套（"甲日临未"） |

即：三命所称"阳贵（甲丑）"，在命理约言正是"夏至治阴"之贵；地支相同而阴阳标签
相反。两套均**跳辰（天罗）、跳戌（地网）**，三命另指出阳贵跳子、阴贵跳申
（贵人不再临起贵之方），此套逐干推演为五行精纪所无，是三命的补层。

- 命理约言只承认**一个贵人随二至移方**：「冬至后则由井鬼之次而起顺行」「夏至后
  则由斗牛之间而起逆行」，「惟辰为天罗，戌为地网，不临其方」，并明斥「说者误以
  为十干之贵人，又误为十干各有阴贵阳贵，将贵人有十二矣」。

### 2.3 "二至阴阳" 还是 "昼夜寅申"——三命内部即存两说

- 一说（三命倾向）：「其曰阳贵阴贵，乃冬至用阳、夏至用阴，非昼夜之说」。
- 一说（《壶中子》）：「贵人分治昼夜，各自专权，以昼生遇昼贵、夜生遇夜贵为得力」，
  五行精纪亦录「子后为昼、午后为夜」（`wxjj_v14_01` 引《壶中子》《三历会同》）。
- 三命万民英裁断：以子后午后、日出日入分昼夜「皆是臆说，不若只以寅申分阴阳，
  冬至后用阳贵、夏至后用阴贵」；命理约言更进一步，否认一日之内朝暮再移方。
- **命名对调的根源**：三命与命理约言虽都说"冬至用阳、夏至用阴"，但对"阳贵起于
  何位"理解不同——三命以先天坤在**子**、阳贵从子上起甲顺行（得甲丑）；命理约言以
  冬至由井鬼之次（**未**）起甲顺行（得甲未）。起点一异，同名"阳贵"所取之套正相反，
  此即 §2.2 命名对调的由来。因此落地时只认两套临支（A/B）与所选起例规则，
  不依赖"阳贵/阴贵"字面。
- **工程提示**：若排盘要算"昼贵/夜贵"，属可选规则，应作为开关而非定论，默认采用
  二至阴阳说，并在 UI 标注存在壶中子昼夜异说。

## 3. "十干何以贵此支"义理对照

五行精纪（引关东叟/广录）与三命通会（引阎东叟/三车一览/广录）义理几乎逐句同源，
可互为校本：

| 干组 | 所贵支 | 义理（两书共持） |
|---|---|---|
| 甲戊庚（阳干） | 丑未（牛羊） | 阳木阳土阳金喜归土位/印库；甲尤喜未、庚尤喜丑，各归其库 |
| 乙己（阴干） | 子申（鼠猴） | 阴木爱阳水、阴土喜生旺，喜于财旺；乙尤喜子、己尤喜申 |
| 丙丁（火） | 亥酉（猪鸡） | 火盛夏害物，息于酉、藏于亥，以西北阴气和之，**水火不嫌死绝** |
| 壬癸（水） | 卯巳（兔蛇） | 水穷冬严杀，啬于卯、潜于巳，以东南温燠之气和之 |
| 六辛（阴金） | 午寅（马虎） | 阴金执方不能自化，假寅午生旺之火锉刚成形，**阴金不嫌鬼胜** |

- 三命通会另引《三车一览》从少阳/少阴之气"用事毕则退藏"作更哲学化的解释，
  为五行精纪所无。
- 两书都强调终须「以纳音互换推寻，须比和则其贵为福」，并举反例：
  「若丙火得酉，火至此死，焉足为贵哉」（`wxjj_v14_01` 广录；三命作「若丙火得酉，
  火至此死焉，足贵哉」）——即**起例只是必要条件，仍须五行喜忌比和**，不可见贵即断吉。
