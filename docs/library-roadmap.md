# Aether-Cycle 五术古籍图书馆 · 长期建设路线图 v1.0

> 定位：**带检索功能的五术古籍图书馆**（山 / 医 / 命 / 相 / 卜）。
> 原则：重索引、轻搜索；原文锁死、元数据驱动；小步频繁 commit、一个 PR 一个主题。
> 本路线图为**长期维护规划**，颗粒度细到「批次(Batch)」，每批次可独立完成、独立验收。

---

## 0. 愿景与总目标（24 个月）

| 维度 | 目标 |
|---|---|
| 典籍覆盖 | **50 部**以上公版权威古籍（命 15 / 医 12 / 相 10 / 卜 8 / 山 5，含核心经典与重要注本） |
| 条目规模 | **5000+** 结构化条目（Frontmatter + 原文 + 古注 + 白话提要三层） |
| 五术覆盖 | 山 / 医 / 命 / 相 / 卜全覆盖，每术有「核心经典 + 重要注本 + 交叉校勘」 |
| 检索能力 | 每术有专属检索维度；五术概念互见索引；线性扫描毫秒级（不做倒排索引） |
| 工程质量 | CI 全绿、golden 对拍、自召回不变量、受控词表、语义化版本 release |
| 校勘深度 | 每术至少 2 篇交叉校勘文档；五术跨术主题校勘至少 3 篇 |

## 2. 五术分类与元数据策略

### 2.1 顶层目录结构
```

├── library/       # 五术典籍内容根目录
│   ├── ming/      # 命：八字 / 紫微斗数 / 七政四余 / 称骨 / 铁板神数

│   ├── yi/        # 医：经典 / 方书 / 本草 / 针灸 / 温病 / 养生
│   ├── xiang/     # 相：人相 / 地相(风水) / 星相

│   │   ├── dixiang/
│   │   └── xingxiang/
│   ├── bu/        # 卜：易经 / 六爻 / 梅花易数 / 奇门遁甲 / 大六壬 / 太乙
│   └── shan/      # 山：丹道 / 养生导引 / 武术 / 符咒 / 存思
```

### 2.2 元数据策略
- **命 · 八字**：保留现有精确 conditions（day_master / month_branch / day_pillar / hour_pillar / ten_god / pattern / shensha / keywords）
- **其他四术**：先用 `category`（五术）/ `subcategory`（子分类）/ `type`（体裁）/ `keywords` 做轻量索引，**不强行套八字 conditions**；每术建设到一定规模后再扩展该术专属 conditions
- 所有条目统一 Frontmatter 八键 conditions（空值 `[]`），新增专属字段时通过 schema 版本升级

## 5. 风险与边界

### 5.1 底本与文本质量
- 优先选择：四库全书本、中华典藏网、古诗文网、国学大师等权威源
- OCR 低质文本不直接入库，需人工校勘或选择更干净底本
- 同一经典多版本并行入库时，明确标注底本与注者，异文记入校勘文档

### 5.2 版权与合规
- 优先公版古籍（作者逝世超 50 年 / 古籍本身公版）
- 现代注本、白话译本谨慎入库（需确认版权或仅作参考链接）
- 所有条目含「传统文化内容仅供研究参考，不作人生决策依据」免责声明

### 5.3 范围控制
- 五术为主（山 / 医 / 命 / 相 / 卜），不扩展到其他术数（如塔罗、星座、数字能量等）
- 「山」术聚焦丹道 / 养生 / 武术 / 符咒，不涉及宗教仪式实操
- 「医」术聚焦古籍文献整理，不提供医疗建议（需加医疗免责声明）

### 5.4 工程边界
- 不做倒排索引 / 复杂排名（线性扫描毫秒级，5000 条足够）
- 不做前端渲染组件（仓库定位为文档库 + 检索引擎，前端由主程序负责）
- 不实现称重 / 排盘 / 起卦等计算逻辑（属主程序，本库只提供原文检索）

## 6. 版本化与 Release 策略

| 版本 | 触发条件 | 示例 |
|---|---|---|
| PATCH (x.y.Z) | 校勘 / OCR 校正 / 白话修正 / bug 修复 | v1.1.1 |
| MINOR (x.Y.0) | 新增一部书 / 新增一个术类的专属 conditions / 检索语义升级 | v1.2.0（新增紫微斗数全书） |
| MAJOR (X.0.0) | 五术全覆盖 / 顶层目录大重构 / schema 不兼容升级 | v2.0.0（五术全覆盖） |

- 每批次完成后打 annotated tag
- 每术完成后打 minor release + `gh release create --generate-notes`
- 五术全覆盖后打 `v2.0-five-arts-complete`
- tag 与 release 说明包含：新增书目、条目数、校勘文档、breaking changes

## 7. 路线图维护机制
