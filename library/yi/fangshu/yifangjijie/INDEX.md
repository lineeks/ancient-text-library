# 医方集解

**朝代**：清  
**作者**：汪昂  
**来源**：https://github.com/wenyuange/medicine  

## 简介

《医方集解》为清代汪昂所著，按方剂治法分类（补养、发表、涌吐、攻里等），收载正方三百余首，是清代以来流传最广的方剂学入门书。
