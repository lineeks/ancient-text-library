# 医学衷中参西录

**朝代**：清  
**作者**：张锡纯  
**来源**：https://github.com/wenyuange/medicine  

## 简介

《医学衷中参西录》为近代中西医汇通学派代表人物张锡纯所著。全书分医方、药物、医论、医话、医案五部分，结合中西医学理论，记载大量自创方剂与临床验案。
