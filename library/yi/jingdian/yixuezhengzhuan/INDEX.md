# 医学正传

**朝代**：明  
**作者**：虞抟  
**来源**：https://github.com/wenyuange/medicine  

## 简介

《医学正传》为明代虞抟所著，以问答体阐述医学理论、诊断辨证与临床方药，上承《内经》《难经》，下采朱丹溪等诸家学说，是明代重要医学入门书。
