# 医（中医）

五术之「医」：中医药经典文献。

## 子分类
- `jingdian/` — 中医经典（现有 5 部 556 条：黄帝内经素问、灵枢经、八十一难经、伤寒论、神农本草经）
- `fangshu/` — 方书（现有 2 部 70 卷：备急千金要方、外台秘要）
- `wenbing/` — 温病（现有 1 部 6 卷：温病条辨）
- `zhenji/` — 针灸（现有 1 部 12 卷：针灸甲乙经）
- `zhenfa/` — 诊法（现有 1 部 1 卷：脉经，待校勘补全10卷）
- `bencao/` — 本草（待补：本草纲目）
