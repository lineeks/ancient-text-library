# 卜筮正宗

中华典藏网，清王维德字洪绪号林屋先生撰，卷一启蒙节要14条，六爻进阶核心典籍，全书14卷，以黄金策为纲，系统阐述六爻占断之法，启蒙节要涵盖纳音五行、六亲、以钱代蓍、六十四卦装卦、纳甲、六兽、三合、长生、禄马羊刃、三刑六害、通玄赋、碎金赋、持世、世应、飞伏、用神、旬空月破等核心歌赋，力辟诸书之谬，一宗正理，为六爻学之集大成之作。
