# 卜（卜筮）

五术之「卜」：以卦象推占的术数。

## 子分类
- `yijing/` — 易经（现有 1 部 68 条：周易，64卦+4传）
- `liuyao/` — 六爻（待补：火珠林、卜筮正宗、增删卜易）
- `meihua/` — 梅花易数（待补：梅花易数）
- `qimen/` — 奇门遁甲（待补：奇门遁甲秘笈大全、烟波钓叟歌）
- `liuren/` — 大六壬（待补：大六壬指南、六壬大全）
- `taiyi/` — 太乙神数（待补：太乙金镜式经）

## 已有典籍
周易（64卦+系辞/说卦/序卦/杂卦4传）
