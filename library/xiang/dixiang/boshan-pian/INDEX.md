# 博山篇

五代黄妙应（妙应禅师）撰，中华典藏网，8章，形法派峦头风水代表作，口诀体，概论相地法+论龙+论穴+论砂+论水+论明堂+论阳宅+论平地，重在寻龙点穴实操法则，为峦头风水入门之经典。
