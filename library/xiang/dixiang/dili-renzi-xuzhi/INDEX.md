# 地理人子须知

明徐善继、徐善述（江右德行山人，孪生兄弟）撰，中华典藏网（明万历重刊本），51篇，全称《重刊人子须知资孝地理心学统宗》，万历年间堪舆集大成巨著，形峦风水教科书级典籍，8卷全面系统阐述龙穴砂水四大核心（卷一龙法/卷二穴法/卷三砂法/卷四水法/卷五阳宅/卷六阴宅/卷七穴法补/卷八杂论），考证风水名家历代案例甚多，为古代记载案例最多的堪舆著作，形峦家无不推荐。
