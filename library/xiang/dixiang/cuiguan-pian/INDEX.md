# 催官篇

宋赖文俊（字太素，号布衣子，世称赖布衣）撰，中华典藏网，4卷，天星风水代表作，歌诀体，评龙+评穴+评砂+评水，以二十四山分阴阳、三吉六秀（震庚亥为三吉，巽辛艮丙兑丁为六秀）论龙穴砂水之吉凶应，为理气派天星风水之经典。
