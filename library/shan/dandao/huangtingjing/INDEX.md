# 黄庭经

题太上老君授，魏晋上清派核心经典，40条（内景36章+外景3章+胎息经），七言歌诀体，详述人身五脏六腑、三丹田、泥丸九宫之神真，教人存思身中诸神、漱咽灵液、固精守气。
