# 五禽戏（太上老君养生诀）

中国道教协会《太上老君养生诀》，汉末华佗授广陵吴普，9条（五禽总述1+虎鹿熊猿鸟5戏+服气吐纳六气1+养生真诀1+服气诀1），中国古代导引养生功法，模仿五种动物动作，以汗出为限，可轻身消谷益气除百病，与八段锦、易筋经并称养生三典。
