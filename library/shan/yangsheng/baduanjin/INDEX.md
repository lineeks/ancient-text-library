# 八段锦

抖音百科整理，起源宋朝，10条（总述1+立式8式+坐式口诀1），中国古代导引养生功法，分立功、坐功两部分，共八段，每段一个动作，包括肢体运动和气息调理，练习时配合意守、呼吸及以意领气，为养生导引之经典功法。
