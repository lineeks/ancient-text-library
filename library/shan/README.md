# 山（仙学/养生/武术）

五术之「山」：修身养性、强身健体的术数，含丹道、养生导引、武术、符咒。

## 子分类
- `dandao/` — 丹道（现有 1 部 66 条：周易参同契分章通真义）
- `yangsheng/` — 养生导引（现有 1 部 22 条：达摩洗髓易筋经）
- `wushu/` — 武术（现有 1 部 1 条：太极拳论）
- `fuzhou/` — 符咒（待补：万法归宗）

## 已有典籍
周易参同契分章通真义（汉魏伯阳·五代彭晓注，丹道鼻祖）、太极拳论（清王宗岳）、达摩洗髓易筋经（含易筋经十二势、八段锦、十二段锦）
