# 命（命理）

五术之「命」：以出生时间推命的术数。

## 子分类
- `bazi/` — 子平八字（现有 11 部 1672 条，含 `core/` `origin-shensha/` `extended/` 三个梯队）
- `ziwei/` — 紫微斗数（待补：紫微斗数全书、紫微斗数全集）
- `qizheng/` — 七政四余（待补：果老星宗、星学大成）
